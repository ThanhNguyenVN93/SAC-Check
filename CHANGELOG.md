# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- Initial release
- Smart App Control status checker
- Enable/Disable SAC functionality
- Dark Mode Minimalist UI (Hiku design)
- .NET 3.5 automatic detection and activation
- OS version detection and compatibility check
- System date/time display in title bar
- Keyboard shortcut (ESC to exit)
- Real-time SAC status updates
- Button hover effects
- Admin privilege verification
- Registry modification capability

### Features
- Support for Windows 11 Build 22621+
- Auto-enable .NET Framework 3.5
- Color-coded status display
- Terminal-style output (Lime Green text)
- Cyan hyperlinks for more information
- DISM integration for .NET setup

### Security
- Administrator privilege requirement check
- UAC integration
- Secure registry access
- Manifest-based admin request

### UI/UX
- Dark Theme (#1E1E1E background)
- Flat button style with border-less design
- Smooth color transitions on hover
- Responsive layout
- Centered window positioning
- Professional font (Segoe UI)
